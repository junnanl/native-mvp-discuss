# v1.0.3 运行配置持久化补丁

## 目的

本补丁解决前台模型配置在增量补丁或容器重建后丢失的问题。

补丁会把 CowAgent 的运行配置文件持久化到宿主机：

```text
/opt/cowagent-offline/storage/cow/app-config/config.json
```

同时会从运行配置生成技能环境变量文件：

```text
/opt/cowagent-offline/storage/cow/env-config/.env
```

并通过 Docker Compose 挂载到容器：

```text
/app/config.json
/root/.cow
/home/agent/.cow
```

之后前台保存的主模型、多模态视觉模型、向量模型、上下文长度、Web 密码等运行配置都会写入宿主机持久化文件。MinerU 等读取 `~/.cow` 的 Skill 会从 `storage/cow/env-config/.env` 读取配置。后续品牌补丁、Skill 补丁、容器重启或重建不会要求重新配置。

当 `/app/config.json` 已挂载后，该文件是模型和智能体参数的唯一运行主配置。启动命令会清除 Compose 中用于首次初始化的模型、Embedding、Rerank 和 Agent 上下文环境变量，避免它们在每次容器启动时覆盖前台已经保存的配置。

如果模型服务运行在 CowAgent 宿主机上，容器内 Base URL 不得写 `127.0.0.1`，应使用 `host.docker.internal`；补丁已加入 `host.docker.internal:host-gateway` 映射。模型服务位于其他内网服务器时，继续填写实际内网 IP 或域名。

## 应用方式

如果已经准备好现场配置文件：

```bash
cd /opt/cowagent-offline
tar -xzf cowagent-patch-v1.0.3-runtime-config-persistence.tar.gz
cd patch-v1.0.3-runtime-config-persistence
TARGET_ROOT=/opt/cowagent-offline CONFIG_SOURCE=/path/to/cowagent-runtime.config.json bash scripts/apply.sh
```

如果不指定 `CONFIG_SOURCE`，脚本会优先从当前运行容器的 `/app/config.json` 复制配置；如果容器中不存在，则从镜像模板初始化，并合并 `compose/.env` 中的主模型和上下文参数。

## 验证

```bash
TARGET_ROOT=/opt/cowagent-offline bash scripts/verify.sh
```

成功标志：

```text
INFO: runtime config persistence verify passed
```

## 注意

标准补丁包不包含真实模型 Key。真实配置文件由现场一键包提供，现场一键包的默认 `install.sh` 会通过 `CONFIG_SOURCE` 把包内配置写入运行配置。
