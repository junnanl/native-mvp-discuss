# v1.0.3 回滚说明

执行：

```bash
cd /opt/cowagent-offline/patch-v1.0.3-runtime-config-persistence
TARGET_ROOT=/opt/cowagent-offline bash scripts/rollback.sh
```

回滚会恢复应用补丁前的 `compose/docker-compose.override.yml`。

如果应用补丁前已经存在宿主机运行配置文件，也会恢复该文件的备份版本。

如果应用补丁前不存在运行配置文件，回滚不会主动删除当前的：

```text
/opt/cowagent-offline/storage/cow/app-config/config.json
/opt/cowagent-offline/storage/cow/env-config/.env
```

这是为了避免误删现场已经确认过的模型配置。需要彻底清理时，应先备份该文件，再由运维人员手动处理。
