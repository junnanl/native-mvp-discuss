# v1.0.4 OfficeCLI Toolpack 更新说明

本包只能在 `v1.0.3-runtime-config-persistence` 验证通过后部署。

更新内容：

- 增加固定版本 OfficeCLI `v1.0.134` Linux x64 单文件二进制。
- 增加 CowAgent `officecli` 离线适配 Skill，并在前台启用。
- 保留现场已有的 `docx`、`xlsx`、`pptx`、`Word / DOCX` Skill 及其启用状态。
- 不执行 npm、pip、pnpm、MCP 注册或任何联网安装。
- 不修改模型配置、对话、知识库、上传文件和其他运行数据。

解压后执行：

```bash
bash update.sh
```

默认安装目录为 `/opt/cowagent-offline`，脚本会自动备份、应用、重启并验证。
