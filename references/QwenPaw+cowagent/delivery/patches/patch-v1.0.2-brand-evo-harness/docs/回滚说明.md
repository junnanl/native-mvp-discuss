# Evo-Harness 品牌补丁回滚说明

回滚命令：

```bash
cd patch-v1.0.2-brand-evo-harness
TARGET_ROOT=/opt/cowagent-offline bash scripts/rollback.sh
```

回滚行为：

- 恢复补丁应用前的 `patch-mounted` 目录。
- 如果应用前存在 `compose/docker-compose.override.yml`，则恢复该文件。
- 如果应用前不存在 `compose/docker-compose.override.yml`，则删除本补丁写入的 override。
- 重启服务并执行补丁校验。
