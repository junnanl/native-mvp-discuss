# Evo-Harness 品牌补丁更新说明

补丁版本：`1.0.2-brand-evo-harness`

适用首装包版本：`1.0.0`

适用 CowAgent 版本：`2.1.2`

本补丁只更新 Web 可见品牌，不升级基础镜像，不新增系统、Python、Node 或二进制依赖。

更新内容：

- 页面产品名改为 `Evo-Harness`。
- 替换 Web logo、favicon 和保留原始 logo PNG 资产。
- 隐藏外部文档、官网、GitHub、技能广场入口。
- 侧边栏版本显示改为 `Evo-Harness v1.0.0`。
- 后端 `/config` 默认标题改为 `Evo-Harness`。
- 新增 Compose override，通过启动时 bootstrap 将 `patch-mounted/frontend` 覆盖到容器 `/app/channel/web`。

应用方式：

```bash
tar -xzf cowagent-patch-v1.0.2-brand-evo-harness.tar.gz
cd patch-v1.0.2-brand-evo-harness
TARGET_ROOT=/opt/cowagent-offline bash scripts/apply.sh
TARGET_ROOT=/opt/cowagent-offline bash scripts/verify.sh
```
