# 补丁更新说明

补丁版本：`1.0.1`

当前补丁包是开发态结构模板，正式增量补丁尚未冻结。

可放入：

- `patches/frontend/`
- `patches/backend/`
- `patches/plugins/`
- `patches/skills/`
- `patches/config/`

当前模板中的办公 Skill 依赖 `cowagent-offline:2.1.2-base.2-dev`。如果新增依赖，请先判断是否需要 toolpack、sidecar 镜像或基础镜像升级；不能要求客户现场执行 `pip install`、`npm install`、`npx` 或 `uvx` 在线拉取。
