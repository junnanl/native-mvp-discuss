# MCP SSH Manager 现场配置

## 1. 直接在 CowAgent 对话中配置

部署完成后，直接对 CowAgent 发送：

```markdown
新增一个 SSH 连接：
名称：test
IP：10.0.0.10
端口：22
账号：root
密码：实际密码
```

CowAgent 会调用已安装的 `ssh-manager-admin` Skill，把连接写入：

```text
/opt/cowagent-offline/storage/cow/mcp-ssh-manager/config/servers.toml
```

文件由脚本以 `600` 权限原子写入。MCP 会检测配置变化，后续可直接按连接名称调用，不要求用户进入容器、执行安装命令或手工编辑配置。

也可以在对话中说“查看 SSH 连接”“删除 SSH 连接 test”或“把 test 改为只读模式”。列表不会显示密码或口令。

## 2. 权限模式

新连接默认使用 `unrestricted`，全部功能可用：

- `unrestricted`：允许完整的远程命令、上传、同步、部署、sudo、数据库和备份能力。
- `readonly`：阻止会修改远端状态的命令和工具。
- `restricted`：只允许匹配 `allowPatterns` 的命令，上传、同步等工具仍会受限。

权限模式可在新增连接时指定，也可以后续直接在 CowAgent 对话中修改，不要求手工改 TOML；管理脚本会保留原连接中未修改的账号和凭据。

`readonly` 会阻止上传、同步、部署、sudo、数据库导入等写工具，并拦截常见文件创建、覆盖、删除和服务变更命令。Shell 命令模式匹配属于防误操作措施，不是操作系统级隔离；要求严格命令边界时使用 `restricted` 白名单，并配合远端低权限账号。

## 3. 私钥

私钥由现场运维写入：

```text
/opt/cowagent-offline/storage/cow/mcp-ssh-manager/home/.ssh/
```

私钥权限必须为 `600`。私钥不得放入补丁包、日志包或普通文档。

## 4. 主机密钥

首次连接采用 TOFU：MCP 接受当前收到的主机密钥，并立即写入专用 `known_hosts`。以后使用同一连接时会严格比对；密钥发生变化则停止连接，避免误连到其他主机。

服务器重装或正常轮换密钥后，先确认变化确实来自目标服务器，再对 CowAgent 说：“确认重新信任 SSH 连接 test 的主机密钥。”CowAgent 会删除该连接的旧记录，下一次连接自动记录新密钥。

本机制不依赖 HTTPS；SSH 主机密钥是 SSH 协议自身的服务器身份校验。

## 5. 37 个工具与开关

默认 `all`，上游 37 个工具全部启用。可以直接对 CowAgent 说：

- “SSH Manager 恢复全部工具。”
- “SSH Manager 只保留 5 个核心工具。”
- “关闭 backup 工具组。”
- “关闭 ssh_execute_sudo，其他工具保持开启。”

工具组包括 `core`、`sessions`、`monitoring`、`backup`、`database` 和 `advanced`。工具清单在新的 MCP 进程中加载；当前会话没有刷新时只需重启 CowAgent 服务，不需要修改配置文件。

## 6. 离线依赖

Toolpack 已包含：

- Node.js 生产依赖和完整 `node_modules`。
- `rsync 3.2.3`。
- `sshpass 1.09`。
- OpenSSH Client 8.4p1：`ssh`、`scp`、`sftp`、`ssh-keyscan`、`ssh-keygen`。
- 上述程序在 CowAgent 基础镜像中缺失的共享库。

现场不执行 npm、pnpm、npx、apt 或 git。补丁验证会在 CowAgent 容器内实际启动这些离线二进制，并通过原生 stdio 握手核对 37 个工具。

## 7. 数据库连接

MySQL、PostgreSQL 和 MongoDB 连接也可以直接在对话中持久化。例如：

```markdown
新增数据库连接：
名称：prod-db
所属 SSH 连接：test
类型：postgresql
数据库主机：localhost
端口：5432
账号：app_user
密码：实际密码
默认数据库：app
```

数据库连接档案与 SSH 连接一起保存在 `servers.toml`，权限为 `600`。后续 CowAgent 调用 `ssh_db_dump`、`ssh_db_import`、`ssh_db_list` 或 `ssh_db_query` 时只传 `dbProfile=prod-db`，MCP 在内部读取凭据，不要求再次输入密码，也不会把已保存密码放回 MCP 参数。

每个数据库档案绑定一个 SSH 连接，因为数据库命令是在对应 SSH 服务器上执行。数据库地址应填写从该 SSH 服务器可访问的地址；同机数据库通常是 `localhost`。

## 8. 凭据说明

补丁包不包含任何现场 SSH 或数据库信息。用户在聊天中发送密码后，密码可能进入 CowAgent 对话数据库或模型请求日志；配置脚本不会额外回显密码，但不能把聊天明文凭据视为完全不留痕。能使用私钥时优先使用专用低权限账号和私钥认证。
