# v1.0.6 MCP SSH Manager 更新说明

本包只能在 `v1.0.5-html-report` 验证通过后部署。

更新内容：

- 增加固定版本 `mcp-ssh-manager v3.7.0`，上游提交为 `5c3a8137a3d8e083708770f067cada948d16022b`。
- 生产 Node.js 依赖和 `node_modules` 已完整离线固化。
- `rsync`、`sshpass`、OpenSSH 客户端及其缺失的共享库已随 Toolpack 固化，37 个工具涉及的本地命令不依赖现场安装。
- 客户内网不运行 npm、pnpm、npx、apt 或 git，也不要求连接公网。
- 通过 CowAgent 原生 `mcp.json` 注册 stdio MCP，不增加容器、端口或系统服务。
- 默认启用上游全部 37 个工具，包括命令、上传下载、同步、会话、监控、备份、数据库、部署、sudo、隧道和高级管理能力。
- 新增 `ssh-manager-admin` Skill。用户可直接在 CowAgent 对话中提供连接名称、IP、端口、账号和密码，由 CowAgent 自动持久化，无需手工编辑配置文件。
- MySQL、PostgreSQL、MongoDB 连接也可通过对话保存为档案；4 个 `ssh_db_*` 工具只需档案名称即可在 MCP 内部读取凭据。
- 服务器默认使用 `unrestricted` 以保证完整功能；也可按连接改为 `readonly` 或 `restricted`。
- SSH 主机密钥首次连接自动接受并记录，后续发生变化时拒绝连接；用户确认服务器重装或密钥轮换后可在对话中重新信任。
- 补丁不包含服务器地址、账号、密码、私钥或其他现场凭据。

部署后可直接在 CowAgent 对话中新增连接，操作示例见 `docs/配置说明.md`。
