# v1.0.5 HTML Report Skill 更新说明

本包只能在 `v1.0.4-officecli-toolpack` 验证通过后部署。

更新内容：

- 增加固定提交的社区 `TheoRata/Report-Skill` CowAgent 离线适配。
- 增加 `html-report` Skill，并在前台启用。
- 生成可下载、可断网打开的单文件 HTML 汇报材料。
- 禁止 CDN、在线字体、远程脚本和现场 npm/pip 安装。
- 不引入 `nexu-io/html-anything`，不新增容器和外部端口。
- 不修改模型配置、OfficeCLI、对话、知识库和上传文件。

解压后执行：

```bash
bash update.sh
```

默认安装目录为 `/opt/cowagent-offline`，脚本会自动备份、应用、重启并验证。
