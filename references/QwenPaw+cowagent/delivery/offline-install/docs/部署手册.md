# CowAgent 离线部署手册

## 1. 前置条件

客户服务器需已安装：

- Docker
- `docker compose` 或 `docker-compose`

客户现场不需要联网，不执行拉镜像、拉源码、安装依赖或构建镜像。

## 2. 安装

解压离线包后执行：

```bash
./scripts/install.sh /opt/cowagent-offline
```

安装完成后编辑：

```bash
/opt/cowagent-offline/compose/.env
```

至少确认：

```text
COW_WEB_PORT=9899
COW_COMPOSE_PROJECT_NAME=cowagent-offline
COW_CONTAINER_NAME=cowagent-offline
COW_WEB_PASSWORD=
MODEL=deepseek-v4-pro
OPEN_AI_API_BASE=
OPEN_AI_API_KEY=
```

如果同一台服务器部署多套实例，`COW_WEB_PORT`、`COW_COMPOSE_PROJECT_NAME` 和 `COW_CONTAINER_NAME` 必须分别使用不同值。

真实 key 只写入客户服务器 `.env`，不写入交付包。

## 3. 启动

```bash
/opt/cowagent-offline/scripts/start.sh
```

访问：

```text
http://<服务器IP>:<COW_WEB_PORT>
```

## 4. 停止

```bash
/opt/cowagent-offline/scripts/stop.sh
```

停止不会删除运行数据。

## 5. 验证

```bash
/opt/cowagent-offline/scripts/verify.sh
```

## 6. 日志采集

```bash
/opt/cowagent-offline/scripts/collect-logs.sh
```

日志包生成在：

```text
/opt/cowagent-offline/storage/logs/support-bundles/
```

## 7. 浏览器能力

首装包同时启用 CowAgent 原生 `browser` 和官方 `browser-use` Skill。普通网页操作继续使用原生能力；遇到点击不准、复杂组件、Accessibility Tree、CDP 或需要截图验证的任务，CowAgent 会使用本地 `browser-use` MCP。

browser-use MCP 通过 stdio 启动，不开放额外端口，不使用 Dashboard、VNC、HTTP 包装服务或第三方 browser-use MCP server。工具固定为 `browser_exec` 和 `browser_screenshot`，运行依赖已随 Toolpack 和 2.1.7 镜像交付。

浏览器运行数据位于 `storage/cow/browser-use/`，截图和临时文件位于该工作区内。不会导出 Cookie、密码或令牌。
