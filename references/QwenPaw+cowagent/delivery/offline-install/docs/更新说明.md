# 更新说明

首装包版本：`1.1.0`

当前状态：首版交付候选包。

CowAgent 基线版本：`2.1.7`

回滚基线：`2.1.2`（镜像和原首装包资产保留在 `images/`）

本包提供：

- CowAgent Web 服务离线部署结构
- 宿主机端口配置
- 运行数据挂载
- 补丁挂载目录
- 首装默认工作区 seed：预置干净工作区文件和 8 个办公 Skill
- toolpack 预留目录
- 一键安装、启动、停止、验证和日志采集脚本
- 预置办公 Skill 目录结构：`xlsx`、`docx`、`official-writing`、`markdown-converter`、`Word---DOCX`、`pdf`、`pptx`、`eda-reporter`
- 新增官方 `browser-use` Skill 和固定 `browser-use 0.13.8` CLI-MCP Toolpack。只提供 `browser_exec`、`browser_screenshot`，不替换原生 browser。

当前开发基础镜像 `cowagent-offline:2.1.7-base.1-dev` 已固化办公能力依赖和 Chromium，包括 LibreOffice、pandoc、poppler、tesseract、Node 24.18.0、`docx`、`pptxgenjs`、`markitdown` 和常用 Python 分析包。

browser-use Toolpack 固定 Python 3.11.15、`browser-use 0.13.8`、`browser-harness 0.1.9` 及其依赖；部署阶段不执行 `uvx`、`pip install`、`playwright install`，不启用 Cloud、tunnel 或匿名遥测。

注意：正式交付以 `dist/` 下本次重新构建的 tar.gz 和 SHA256 为准。开发态 `storage/` 不进入首装包。
