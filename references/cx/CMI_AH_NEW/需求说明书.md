# CMI_AH 项目需求说明书

## 1. 项目概述

### 1.1 项目背景
CMI_AH（China Mobile Intelligent Assistant - Anhui）是中国移动安徽公司的项目管理系统，旨在实现项目全生命周期管理，涵盖商机管理、项目管理、业财管理等核心业务领域，为解决方案经理和管理层提供高效的业务支撑平台。

### 1.2 项目目标
- 统一项目管理入口，实现商机到项目的全流程跟踪
- 提供效益预评估功能，支持项目投资决策
- 支持多角色协作，包括解决方案经理和领导驾驶舱视图
- 实现数据可视化，辅助管理层决策

### 1.3 技术架构
| 层级 | 技术栈 |
|------|--------|
| 前端框架 | React 18 + TypeScript |
| 构建工具 | Vite 6 |
| 样式方案 | TailwindCSS 3 |
| 状态管理 | Zustand |
| 图标库 | Lucide React |
| 路由管理 | 自定义路由（onNavigate模式） |

## 2. 功能需求

### 2.1 角色与权限

| 角色 | 职责描述 |
|------|----------|
| 解决方案经理 | 日常方案支撑、项目处理、效益预评估 |
| 领导 | 全维度数据驾驶舱、决策支持 |

### 2.2 工作台模块

#### 2.2.1 解决方案经理工作台
- **关键指标展示**：商机数量、中标金额、回款金额、欠费金额、项目数量、在建项目
- **待办事项**：待办任务列表，支持优先级标识
- **公告通知**：系统公告展示，支持重要级别区分
- **快捷操作**：常用功能入口

#### 2.2.2 领导驾驶舱
- **阶段项目统计**：方案、甄选、投标、合同、实施、验收、维保各阶段项目数
- **签约情况**：大单数量、优质单数量、中标数量、直接签约数量及金额
- **收入情况**：计划金额、实际金额、回款金额、欠费金额
- **地市排行**：按项目数量、大单数量、签约金额、回款金额等维度排名
- **行业排行**：9大行业（党政、融合执法、金融、农商、工业能源、互联网、交通、教育、医卫）的项目数量和金额统计
- **TOP项目展示**：重点项目列表

### 2.3 待办管理模块

#### 2.3.1 待办列表
- **一级Tab**：待办、待阅、提醒、已办
- **二级Tab**：全部、商机管理、售前支撑、立项决策、投标、合同管理、合同交底、项目开工、项目启动与规划、收入管理、支出管理、其他

#### 2.5.7 效益预评估（重点功能）

**2.5.7.1 主页面功能**
- **附件解析**：支持上传 .xlsx/.xls/.csv 文件进行解析
- **模板下载**：提供效益预评估模板下载
- **数据展示**：24项评估指标展示（3列布局）
- **在线填写入口**：跳转在线填写页面

**2.5.7.2 在线填写功能**

包含10大业务区块：

| 区块 | 功能描述 |
|------|----------|
| 项目概况 | 项目基本信息展示区域 |
| 效益预评估 | 24项只读评估指标展示 |
| 收入-IT部分 | IT计划收入管理（新增/编辑/删除） |
| 收入-CT部分 | CT计划收入管理（新增/编辑/删除） |
| 投入-IT成本 | IT成本管理（新增/编辑/删除） |
| 投入-CT成本 | CT成本管理（新增/编辑/删除） |

**关键联动逻辑**：
- CT计划：计费分摊类型与计费周期联动（一次性→1个月，月→12个月）

- 资费选项：根据收入部分已选资费动态限制可选范围
- 税率联动：选择资费后自动带出对应税率

6. 净现值(元)
7. 项目总收入(元,不含税)
8. 项目总投入(元,不含税)
9. 净现值率
10. 合同净现值率
11. IT净现值率
12. 合同IT净现值率
13. 内部收益率(IRR)
14. 收入利润率
15. 项目整体毛利率
16. 项目增值税(元)
17. IT投资(元,不含税)
18. IT部分毛利率
19. 是否融自有能力
20. 分摊部分(元)
21. CT收入利润率
22. 动态回收期(年)
23. 静态回收期(年)

25. IT通服毛利率

## 3. 非功能需求

### 3.1 性能需求
- 页面加载时间 ≤ 2秒
- 数据查询响应时间 ≤ 1秒
- 支持100+并发用户

- 系统可用性 ≥ 99.9%
- 故障恢复时间 ≤ 1小时

### 3.3 安全性需求
- 用户身份认证

- 支持主流浏览器（Chrome、Firefox、Safari、Edge）

## 7. 关键业务流程

### 7.1 效益预评估流程

```
开始 → 进入主页面
        ↓
    选择方式
    ↓         ↓
  附件上传  在线填写
    ↓         ↓
  文件解析  填写各区块数据
    ↓         ↓
  展示结果  自动计算评估指标
    ↓         ↓
  完成评估  完成评估

```

