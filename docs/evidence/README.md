## 走查覆盖什么

一句话 → 路由 → AI 填表 → 人确认 → 提交 → 评审（含重复建设检测）→ 开发（AI 出草稿）
→ 员工上岗 → 使用者看到卡片 → **同一个输入框**发起报销 → 主管批 → 财务批 → 完成
→ 查数据出图表 → 进对话页看真实工具事件与画布产物。

## 走查不能证明什么

**模型是桩，CowAgent 也是按 `references/QwenPaw+cowagent/API_CALLING.md` 协议写的桩**
（脚本在会话的临时目录里，不入库）。

桩验证的是**我们这边**的东西：结构化输出的校验与重试、`response_format` 不被支持时的
降级、CowAgent 事件的投影、三栏与画布的渲染。

它**不能**证明真实内网模型稳定，也**不能**证明真实 CowAgent 实例可用。
这两项是方案 §8 的待验项，至今未验。
